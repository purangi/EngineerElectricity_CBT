# 전기기사 CBT 문제은행 (EngineerElectricity_CBT)

전기기사 필기시험을 CBT(Computer Based Test) 형식으로 풀어볼 수 있는 **단일 HTML 웹앱**입니다.
기출 복원문제와 자체 연습문제를 과목·소분류별로 정리해 풀고, 꼬리질문까지 포함된 상세 해설로 복습할 수 있습니다.

서버·빌드·설치가 필요 없으며, `Electricity_CBT.html` 파일을 브라우저로 열기만 하면 동작합니다.
풀이 기록·즐겨찾기·직접 등록한 문제는 브라우저의 `localStorage`에 저장됩니다.

---

## 주요 기능

- **모의고사** — 과목·범위(전체 / 즐겨찾기 / 오답 위주)·문항 수를 골라 CBT 형식으로 응시하고, 채점 후 오답만 다시 풀 수 있습니다.
- **문제은행** — 과목·소분류·검색어·즐겨찾기 필터로 문제를 둘러보고 개별 풀이/해설을 확인합니다.
- **상세 해설** — 각 문제는 핵심 개념(`concept`), 풀이 단계(`steps`), 그리고 자주 헷갈리는 지점을 짚는 꼬리질문(`selfCheck`)까지 담고 있습니다.
- **즐겨찾기 / 오답 관리** — 문제를 별표로 저장하고, 틀린 문제를 모아 다시 풀 수 있습니다.
- **새 문제 등록** — 앱 안에서 직접 문제를 만들어 풀 수 있습니다(브라우저에 저장).

### 과목 구성 (5과목)

| 코드 | 과목 | 주요 소분류 |
|------|------|-------------|
| `em` | 전기자기학 | 정전계, 정전용량, 유전체, 정자계, 자성체, 전자유도·인덕턴스, 맥스웰 방정식 등 |
| `pw` | 전력공학 | 선로정수·코로나, 안정도, 이상전압, 고장계산, 차단기·보호협조, 조상설비, 발전방식 등 |
| `me` | 전기기기 | 직류기, 동기기, 변압기, 유도전동기, 정류기·전력변환 |
| `cc` | 회로이론 및 제어공학 | 교류회로, 3상회로, 라플라스·과도현상, 전달함수, 안정도판별, 시퀀스제어 등 |
| `reg` | 전기설비기술기준 | 접지시스템, 저압/고압·특고압설비, 전선로·배선, 피뢰설비, 발변전소설비 |

## 작동 방법

### 1. 실행
`Electricity_CBT.html` 파일을 웹 브라우저에서 엽니다 (더블 클릭 또는 브라우저로 드래그).
별도의 서버가 필요 없으며 `file://` 환경에서 바로 동작합니다.

### 2. 구조와 로딩 흐름
```
EngineerElectricity_CBT/
├── Electricity_CBT.html   # 앱 본체 (UI · 상태관리 · 렌더링 · 로직)
├── manifest.js            # 불러올 문제 파일 목록 (PROBLEM_FILES)
├── problems/              # 문제 데이터 (파일 1개 = 문제 1개)
│   ├── me-2025-1-3.js
│   ├── pw-2025-1-11.js
│   └── ...
└── claude-skill/          # 문제 추가용 Claude 스킬 번들 (.skill)
    └── electrical-exam-cbt-bank.skill
```

앱이 로드되면 다음 순서로 동작합니다.

1. HTML이 `manifest.js`를 불러와 `PROBLEM_FILES` 배열(문제 파일 목록)과 빈 `SEED_PROBLEMS` 배열을 선언합니다.
2. `loadProblemScripts()`가 `PROBLEM_FILES`의 각 파일을 `<script>`로 주입합니다. 각 파일은 `SEED_PROBLEMS.push({...})`로 자기 문제 하나를 배열에 채웁니다.
3. `localStorage`에서 사용자 데이터(풀이 기록·즐겨찾기·직접 등록 문제)를 불러온 뒤 화면을 렌더링합니다.

### 3. 데이터 저장
사용자 데이터는 브라우저 `localStorage`(키: `cbt-user-data-v1`)에 저장됩니다.
따라서 **같은 브라우저·같은 기기**에서는 기록이 유지되지만, 다른 기기와는 자동으로 동기화되지 않습니다.

## 새 문제 추가하기

문제 하나를 추가하려면 **문제 파일 1개 + `manifest.js` 한 줄**만 있으면 됩니다. 다른 문제 파일은 전혀 건드리지 않습니다(문제가 많아져도 추가 속도가 느려지지 않는 것이 이 구조의 핵심).

방법은 두 가지입니다. 대화로 문제를 만들며 채워 넣는다면 **Claude 스킬 방식(권장)**, 직접 손으로 넣는다면 **수동 방식**입니다.

### 방법 A — Claude 스킬로 추가하기 (권장)

`claude-skill/electrical-exam-cbt-bank.skill` 은 이 앱 전용 Claude 스킬 번들입니다.
Claude에 이 스킬을 설치해두면, "이 문제 문제은행에 등록해줘" 같은 요청만으로 스키마·taxonomy·정직한 라벨링 규칙에 맞춰 문제 파일을 만들고 `manifest.js`까지 갱신해 줍니다.

- **설치:** Claude Desktop의 Settings → Capabilities(스킬)에서 이 `.skill` 파일을 업로드합니다.
- **동작 방식:** 스킬은 실행할 때마다 프로젝트 폴더(`manifest.js` / `Electricity_CBT.html`)를 스스로 탐색하므로 경로를 고정하지 않습니다. 그래서 이 저장소를 clone한 누구나 그대로 쓸 수 있습니다.
  - **모드 A (파일 접근 가능, 예: Claude Desktop):** `problems/<id>.js`를 새로 만들고 `manifest.js`에 자동으로 등록합니다. 새로고침하면 바로 반영됩니다.
  - **모드 B (파일 접근 없음, 예: 웹/모바일):** `<id>.js`와 갱신된 `manifest.js`를 다운로드 파일로 만들어 줍니다. `<id>.js`는 `problems/` 폴더에 넣고 `manifest.js`는 받은 내용으로 덮어쓰면 됩니다.
- **품질 규칙:** 실제 공식 기출 원문만 `isOfficial:true`로, 기억 기반 복원·자체 구성 문제는 `isOfficial:false`로 라벨링합니다. `explanation.selfCheck`에는 대화 중 실제로 나온 꼬리질문만 정리해 넣습니다.

### 방법 B — 수동으로 추가하기

1. `problems/` 폴더에 새 파일을 만들고 아래 형식으로 문제를 작성합니다.
   파일명은 `과목코드-연도-회차-번호.js`(예: `me-2025-1-3.js`) 규칙을 권장합니다.

   ```js
   SEED_PROBLEMS.push({
     id: "me-2025-1-3",                    // 고유 ID
     label: "2025년 1회 전기기기 3번",       // 목록에 표시될 이름
     subjectId: "me",                      // 과목 코드 (em / pw / me / cc / reg)
     subtopics: ["변압기"],                 // 소분류 (해당 과목의 subtopics 중 선택)
     isOfficial: false,                    // 공식 공개 여부
     question: "문제 지문 ...",
     choices: ["보기1", "보기2", "보기3", "보기4"],
     answer: 1,                            // 정답 보기의 인덱스 (0부터 시작)
     explanation: {
       concept: "핵심 개념 설명 (HTML 태그 사용 가능)",
       steps: ["풀이 1단계", "풀이 2단계", "..."],
       selfCheck: [                        // 꼬리질문 (선택)
         { q: "자주 헷갈리는 질문?", a: "그에 대한 설명" }
       ]
     },
     sourceNote: "출처 메모 (선택)"
   });
   ```

2. `manifest.js`의 `PROBLEM_FILES` 배열에 방금 만든 파일명을 한 줄 추가합니다.

   ```js
   const PROBLEM_FILES = [
     "em-2025-1-8.js",
     // ...
     "me-2025-1-3.js",   // ← 추가
   ];
   ```

3. 브라우저를 새로고침하면 새 문제가 반영됩니다.

## 참고

- 2022년 이후 CBT 회차는 공식적으로 문제가 공개되지 않으므로, 수록된 기출 문제는 교재 등에 실린 **복원본**입니다.
- 순수 프론트엔드(HTML/CSS/JS)로만 구성되어 있어 외부 의존성이나 네트워크 연결이 필요 없습니다.
